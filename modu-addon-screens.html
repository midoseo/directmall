예시 계약 상태 바꿔보기

에스원 본사 계약이 가입한 제공 서비스입니다. 체크를 바꾸면 화면 2의 항목 상태가 바뀝니다.

영상기기 이상 모니터링 상세

  • 진입: 화면 2에서 영상기기 이상 모니터링의 신청 버튼을 누르면 화면 2 안에서 이 상세로 이동합니다. 뒤로 가기를 누르면 목록으로 돌아갑니다.
  • 구성: 서비스명, 상세 설명 → 제공 서비스 카드(이상통보 + 모니터링) → 처리 단계 → 추천 대상 → 대상 기기 → 기기 선택 → 하단에 선택한 기기별 금액, 월 이용료 합계, 취소/신청 버튼. SMS 통보 상세와 같은 하단 구성입니다.
  • 신청 이후: SMS 통보와 같이 신청 내역 확인 → 서명 → 완료로 이어집니다. 신청 항목은 '영상기기 이상 모니터링 (기기명, …)'으로, 청구 예정 금액은 기기별로 표시합니다.
  • 대상 기기 위치: 서비스 안내가 길어져서 대상 기기 안내를 기기 선택 바로 위로 옮겼습니다. 어떤 기기를 고를 수 있는지 선택 직전에 확인하도록 하기 위해서입니다.
  • 기기 선택: 셀렉박스 대신 체크박스 리스트입니다. 여러 대를 함께 신청할 수 있고, 처음에는 아무것도 선택되어 있지 않습니다.
  • 기기 상태: 선택 가능(체크박스 활성), 이용중(체크된 채 잠금), 대상 아님(비활성, 사유 표시), 신청 접수(신청 후 잠금).
  • 신청 버튼: 기기를 하나 이상 고르면 활성화됩니다.

화면 규칙

  • 부가서비스 신청내역: 계약정보의 신청 이력을 누르면 신청내역 목록(총 건수, 구분 배지, 서비스명, 신청일자, 처리상태)이 열리고, 항목을 누르면 신청내역 확인(신청자 정보, 구분, 신청 부가서비스, 신청일자, 접수번호, 내용, 처리상태, 목록 버튼)으로 이동합니다. 신청 완료 화면의 신청내역 보기도 방금 신청한 건의 신청내역 확인으로 연결되고, 목록을 누르면 신청내역 목록으로 갑니다. 앱에서 새로 신청한 건은 목록 맨 위에 추가됩니다.
  • 추천 서비스 확인 말풍선: 계약정보(부가서비스 탭) 하단의 신규 신청 버튼 위에 "추천 서비스 확인" 말풍선을 띄웁니다(마케팅용). 말풍선 꼬리가 신규 신청 버튼을 가리키고, 살짝 위아래로 움직여 눈에 띄게 했습니다(움직임 줄이기 설정에서는 정지). 말풍선을 눌러도 신규 신청과 같이 부가서비스 신청 목록으로 이동합니다.
  • 부가서비스 신청·변경: 전체 메뉴 가입정보의 계약정보 아래에 추가했습니다. 누르면 계약정보 화면의 부가서비스 탭(캡쳐)이 열립니다. 이용중인 부가서비스 건수와 목록, 하단 신청 이력/신규 신청 버튼으로 구성되고, 신규 신청을 누르면 화면 2(부가서비스 신청)로 이어집니다.
  • 비교하기: 제목 옆과 화면 2 위의 비교하기 버튼을 누르면 비대면 신청 가능 서비스 4종(SMS 통보, 영상기기 이상 모니터링, 영상확인 관제 서비스, 모바일카드)의 상세 화면이 한 화면에 나란히 열립니다. 각 화면은 처음 상태로 열리고, 안에서 스크롤하고 항목을 선택해 볼 수 있습니다. 신청, 취소, 뒤로 가기는 동작하지 않습니다. 닫기 버튼이나 Esc로 닫으면 원래 화면으로 돌아갑니다.
  • 신청 중 이탈 후 불러오기: SMS 통보, 영상기기 이상 모니터링, 영상확인 관제 서비스, 모바일카드는 서명 페이지까지 갔다가 신청을 마치지 않고 나가면 선택한 항목이 서비스별로 임시 저장됩니다. 같은 서비스의 신청 버튼을 다시 누르면 "기존 정보가 있어요. 불러올까요?" 팝업이 뜨고, 네를 누르면 저장했던 선택이 채워지며(서명은 다시 받음), 아니요를 누르면 저장본을 지우고 처음부터 시작합니다. 서명을 마쳐 신청을 완료하면 저장본이 삭제됩니다. 팝업에는 서비스명, 저장한 항목, 월 금액, 저장 시각이 보입니다.
  • 계약정보 이후 화면의 헤더: 계약정보(부가서비스 탭), 신청내역 목록과 확인, 부가서비스 신청 목록, 각 서비스 상세, 신규 신청 폼, 신청 내역 확인, 서명 화면의 헤더에 뒤로가기(왼쪽)와 닫기(오른쪽)를 두었습니다. 뒤로가기는 바로 전 페이지로 돌아갑니다(예: 서명 → 신청 내역 확인 → 상세 → 신청 목록 → 계약정보). 닫기는 어디서 눌러도 들어온 곳으로 한 번에 돌아가며, 전체 메뉴로 들어왔으면 전체 메뉴, 메인 배너로 들어왔으면 메인입니다. 신청 중이던 화면은 모두 닫힙니다. 신청 완료 화면은 헤더가 없어 확인 버튼으로 나갑니다.
  • 화면 캡쳐: 각 디바이스 위의 캡쳐 버튼은 해당 화면을, 제목 옆 버튼은 두 화면을 나란히 PNG로 저장합니다. 디바이스 테두리와 바깥 여백 없이 화면 영역만 잘라서 저장합니다. 화면 안에서 스크롤해야 보이는 부분까지 맨 위부터 맨 아래까지 한 장으로 저장하고, 하단 탭이나 하단 버튼 영역은 이미지 맨 아래에 한 번만 들어갑니다. 선택, 입력, 서명한 상태가 그대로 저장되고, '탭하면 계약정보' 같은 설계용 표시는 빠집니다. 저장 전에 미리보기가 나옵니다.
  • 하단 탭 전체: 화면 1 하단의 전체 탭을 누르면 전체 메뉴로 바뀝니다. 구성(가입정보, 시스템 경비(세콤), 영상(CCTV), 카드관리, 이벤트, 혜택, 소통센터, 고객센터, 로그아웃)은 캡쳐 그대로이고, 홈 탭으로 돌아올 수 있습니다. 경비, 영상 탭은 동작하지 않습니다.
  • 배너: 홈 헤더(사용자명, 알림) 바로 아래, 내 경비 구역 위에 둡니다. 높이 60px, 배경 흰색이고 오른쪽 위에 닫기 버튼이 있습니다. 닫으면 배너가 사라지고 아래 내용이 위로 올라옵니다(시안 확인용으로 오른쪽 위 '홈 배너 다시 보기'로 되살릴 수 있음). 메인 화면 배경은 #F5F6FB입니다. 문구의 계약처명은 대표 계약처 이름이 들어갑니다. 누르면 부가서비스 신청 목록이 아니라 계약정보의 부가서비스 탭으로 이동하며(전체 메뉴의 부가서비스 신청·변경과 같은 화면), 신규 신청 버튼을 눌러야 신청 목록으로 이어집니다.
  • 그룹 구조: 시스템경비, 영상, 출입관리, 근태관리, 식당관리, 생활안심 순서와 항목, 설명 문구는 현재 신청 화면 그대로입니다.
  • 카드 구성: 아이콘 영역, 서비스명, 설명 → 비대면 신청 가능 배지 → 금액과 신청 버튼. 배지는 비대면 신청 대상(SMS 통보, 영상기기 이상 모니터링, 영상확인 관제 서비스, 모바일카드)이면서 신청 가능한 항목에만, 금액은 확인된 항목에만 표시합니다. 신청 불가 항목은 아이콘, 서비스명, 설명만 흐리게 보여줍니다.
  • 신청 방식: 체크박스와 하단 취소·다음 버튼을 없애고, 항목마다 신청 버튼을 둡니다.
  • 신청 불가 그룹: 그룹 제목 아래에 "[제공 서비스] 가입 후 신청할 수 있어요"를 한 줄 넣었습니다. 버튼이 없는 이유를 알려주기 위한 추가안이라 빼도 됩니다.
  • 신청 버튼 이후 (비대면 신청 가능): 영상기기 이상 모니터링, 모바일카드, SMS 통보 모두 화면 2 안의 각 서비스 상세로 이동합니다. 신청하기를 누르면 목록으로 돌아가 신청 접수로 표시됩니다.
  • 모바일카드 서비스 상세: 서비스 소개 카드(태그 3개) → 이용 유형 체크박스 다중 선택(모바일카드 무료·필수, 안심방문관리 월 3,300원, 안심배송관리 월 3,300원, 공용부관리 월 5,500원, 대량관리 지사 문의) → 하단에 선택한 유형별 금액, 월 이용료 합계, 취소/신청 버튼. 모바일카드 없이 다른 유형만 고르면 모바일카드 카드가 강조되고 하단에 필수 안내가 나오며 신청 버튼이 비활성화됩니다. 신청 이후는 신청 내역 확인 → 서명 → 완료로 이어집니다.
  • SMS 통보 서비스 상세: 서비스 소개(서비스명, 설명) → SMS 종류 체크박스 다중 선택(노세트 SMS, 무단해제 SMS, 세트해제 SMS, 각 월 5,000원) → 하단에 선택한 종류별 금액, 월 이용료 합계, 취소/신청 버튼. 모바일카드 상세와 같은 구성이고, 대표 이미지는 영상기기 이상 모니터링 상세처럼 넣지 않았습니다.
  • SMS 통보 신청 흐름: SMS 통보 상세 하단은 취소/신청 두 버튼입니다. 신청 → 신청 내역 확인(신청자 정보, 신청 서비스 정보, 청구 예정 금액, 신청하기) → 서명(신청 항목과 금액 요약, 서명란, 서명 완료) → 완료(신청번호, 신청 시각, 신청 항목, 청구 예정 금액, 확인/신청내역 보기). 확인을 누르면 목록으로 돌아가 신청 접수로 표시됩니다.
  • 영상확인 관제 서비스 상세: 서비스 안내(소개 문구, 서비스명, 특징 3가지) → 이런 분들께 추천드립니다(사례 3건) → 신청할 기기 선택(기기별 체크박스 다중 선택, 기기의 채널에 따라 4채널 월 2,200원 · 8채널 월 3,300원 · 16채널 월 4,400원 적용, 아이디스 노바텍 기기만 대상이고 하이실리콘 등 그 외 기기는 '대상 기기가 아니에요'로 비활성) → 하단에 선택한 기기별 금액, 월 이용료 합계, 취소/신청 버튼. 신청 이후는 신청 내역 확인 → 서명 → 완료로 이어집니다. 서비스 안내의 사람 사진은 아이콘으로 바꿨습니다.
  • 목록 정리: 안심배송관리, 안심방문관리, 공용부 모바일카드 관리, 대량 모바일카드 관리는 모바일카드 상세의 이용 유형으로 옮겨서 목록에서 뺐습니다.
  • 신청 버튼 이후 (비대면 신청 불가): 화면 2 안에서 부가서비스 신규 신청 폼으로 이동합니다. 계약처명, 이름, 휴대전화번호, 부가서비스는 자동으로 채워진 읽기 전용이고, 내용은 10자 이상 120자 이내로 입력합니다. 10자 미만이면 확인을 눌렀을 때 입력칸 아래에 안내가 나옵니다. 확인하면 목록으로 돌아가 신청 접수로 표시됩니다.

정해야 할 것

  • 신청 버튼을 누른 뒤 흐름바로 접수할지, 확인 시트를 거칠지. 접수 후 처리 전 상태를 목록에 따로 보여줄지.
  • 근태관리, 식당관리, 생활안심과 '기타'의 신청 조건이 그룹에 해당하는 제공 서비스 계약이 따로 있는지 모릅니다. 예시에서는 미가입으로 두었습니다.
  • 모바일카드 필수 선택 방식지금은 처음에 아무것도 선택되지 않고, 다른 유형만 고르면 안내합니다. 모바일카드를 처음부터 선택된 상태로 잠가 두는 방식도 가능합니다.
  • 서명 단계 유지 여부클릭 동의 기록으로 서명을 갈음할 수 있는지는 법무 확인 전입니다. 갈음이 가능하면 서명 화면 없이 신청하기에서 바로 완료로 갈 수 있습니다.
  • 계약정보 탭 이름캡쳐에서 앞쪽 탭이 잘려 '…금'만 보여, '계약 내용', '청구·입금'으로 임시로 넣었습니다. 실제 탭 이름 확인이 필요합니다.
  • 계약정보 화면의 해지연결할 화면이 아직 없어 안내 토스트만 뜹니다.
  • 신청번호와 접수번호완료 화면은 '신청번호', 신청내역 확인은 '접수번호'로 같은 번호를 다르게 부릅니다. 한 가지 이름으로 맞출지 정해야 합니다.
  • 신청내역의 처리상태 안내 문구'신청' 상태의 안내 문구만 캡쳐로 확인했습니다. '접수', '완료' 상태 문구가 필요합니다.
  • 해지 건의 상세 항목명캡쳐는 신청 건만 있어 해지 건은 '해지 신청 부가서비스'로 임시로 표기했습니다.
  • 앱 신청 건의 내용 항목서명으로 신청한 건은 고객이 내용을 입력하지 않아 내용 항목을 숨겼습니다. 신규 신청 폼으로 접수한 건은 입력한 내용이 표시됩니다.
  • 주소 표시샘플 화면대로 신청 내역 확인에 주소를 넣었습니다. SMS 통보처럼 방문 설치가 없는 서비스에도 주소가 필요한지 확인이 필요합니다.

  • 모바일카드 상세의 상품코드 노출ZSVC0691 같은 코드는 고객에게 의미가 없는 내부 코드일 수 있습니다. 상담 시 식별용으로 필요한지 확인이 필요합니다.
  • 대량관리 설명캡쳐에서 설명 부분이 잘려 있어 이름과 '지사 문의'만 넣었습니다.
  • 신규 신청 폼의 내용 입력최소 10자 조건을 그대로 둘지. 부가서비스명이 이미 채워져 있어 고객이 쓸 내용이 없을 수 있습니다. 선택 입력으로 바꾸는 것도 검토할 만합니다.
