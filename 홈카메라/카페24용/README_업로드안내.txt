[카페24 업로드 안내 — 싱스원 T1 홈카메라 상세페이지]

■ 파일 구성
  index.html          → 상세설명에 붙여넣을 HTML 소스
  images/ (24장)       → ThingsOne_T1_Camera_m_00.jpg ~ m_23.jpg

■ 업로드 절차
  1. 상품관리 > 상품등록(수정) > 상세설명 > 이미지등록(또는 첨부파일)에서
     images 폴더 안 24장을 전부 업로드하세요. (일부만 올리면 본문 이미지가 깨집니다)

  2. 이미지 업로드 후 카페24가 발급하는 이미지 URL
     (예: https://ecimg.cafe24img.com/.../ThingsOne_T1_Camera_m_00.jpg)을 전부 확인하세요.

  3. 상세설명 편집기에서 반드시 'HTML 소스' 모드로 전환한 뒤,
     이 폴더의 index.html 내용을 전체 복사해 붙여넣으세요.

  4. 붙여넣은 소스 안에서 images/ThingsOne_T1_Camera_m_00.jpg ~ m_23.jpg 경로 24개를
     전부 2번에서 확인한 실제 업로드 URL로 찾아 바꿔주세요.

  5. 저장 후 미리보기로 이미지 24장이 전부 정상적으로 보이는지, PC/모바일 화면
     양쪽에서 확인하세요.

■ 절대 하지 말아야 할 것
  · 붙여넣은 뒤 위지윅(에디터) 모드로 다시 전환하지 마세요.
    → 상단 <style> 태그가 통째로 삭제되어 레이아웃이 전부 깨집니다.
  · 표(<th>/<td>) 관련 CSS에 word-break, overflow-wrap 값을 임의로 수정/추가하지 마세요.
    → overflow-wrap:anywhere 를 넣으면 표 최소폭 계산이 틀어져 열이 한 글자 폭으로
      찌그러지는 사고가 난 적이 있습니다. (현재 표는 본문 비노출 스크린리더 전용이라
      평소엔 안 보이지만, 편집 중 실수로 노출 처리하게 되면 이 문제가 그대로 재현됩니다)
  · CSS 순서/구조를 임의로 재배치하지 마세요. (폰트 로딩 → 디자인 → 반응형 처리 순서로
    의존관계가 있습니다)

■ 카페24 관리자 설정 권장
  · [상세설명 이미지 자동 리사이즈] 옵션은 꺼두는 것을 권장합니다.
    켜져 있으면 <img>에 강제로 width가 주입되어 세로 비율이 깨질 수 있습니다.
    (본 HTML에는 이를 방지하는 방어 CSS가 포함되어 있지만, 이중 안전장치로 권장)

■ 알려진 제약사항 (상세설명 HTML로는 해결 불가)
  · 카페24 PC 스킨 공통 레이아웃에 viewport 메타 태그가 없어, 일부 환경에서
    모바일 화면 전체가 축소 렌더링될 수 있습니다. 이 HTML은 화면폭이 아닌
    "삽입된 컬럼 폭" 기준으로 반응하도록 컨테이너 쿼리 처리가 되어 있어
    상세설명 자체는 정상 동작하지만, 몰 전체 축소 문제는 스킨(PC 반응형 전환 또는
    모바일 전용 스킨 분리) 레벨에서 별도로 해결해야 합니다.

■ 이 상품만의 특이사항
  · 원본 파일(index.html, 상위 폴더)은 SEO 메타·Open Graph·JSON-LD 구조화 데이터가
    포함된 독립 페이지용입니다. 이 카페24용 버전은 그 head 정보를 제외하고
    본문(body)만 추출한 버전이므로, 검색엔진 노출용 메타데이터는 포함되어 있지
    않습니다. SEO가 필요하면 원본 index.html을 별도 URL로 호스팅해야 합니다.
