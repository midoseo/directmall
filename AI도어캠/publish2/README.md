# 에스원 AI 도어캠 상세페이지 — 텍스트 살린 버전 (카페24용)

## 방식
PSB의 **텍스트 레이어를 전부 실제 HTML 텍스트로 복원**한 버전입니다.
- 배경(사진·그래픽·아이콘)은 글자를 제거한 이미지 29조각(`images/bg_01~29.jpg`)
- 그 위에 **158개 문구를 실제 텍스트로 절대배치** → 검색엔진이 모두 읽음(SEO 최적)
- 위치·크기·색상·부분 볼드까지 원본과 거의 동일하게 재현
- 폰트는 원본(SamsungOne)과 가장 유사한 무료 웹폰트 **Pretendard**(CDN)로 매칭

## 구성
- `index.html` — 상세페이지 (배경 이미지 + 실제 텍스트 오버레이)
- `images/` — 글자 없는 배경 이미지 29장

## 에이전시 작업 안내
1. `images/`의 이미지 29장을 쇼핑몰 이미지 서버(FTP/에디터)에 업로드합니다.
2. `index.html`의 `src="images/bg_XX.jpg"` 경로를 업로드된 실제 URL로 일괄 변경합니다.
   - 예: `src="//myshop.cafe24.com/web/upload/detail/bg_01.jpg"`
3. 카페24 상세 편집 > HTML 모드에 `<div class="dc"> ... </div>` + 상단 `<style>` + `<link>`(Pretendard)를 붙여넣습니다.

## 폭 조정
기본 폭 860px. 스킨 상세영역이 더 넓으면 `<style>`의 `.dc{ max-width:860px }` 값을 1000~1200px로 변경.
- 텍스트는 컨테이너 폭에 비례(cqw)해 자동 스케일되므로 어떤 폭에서도 배치가 유지됩니다.

## 폰트
- 브라우저가 Pretendard를 CDN에서 자동 로드합니다(인터넷 필요).
- 사내망 등에서 외부 폰트가 막히면 `Noto Sans KR`/`맑은 고딕`으로 자동 대체됩니다.
- 픽셀 단위로 100% 동일한 글꼴이 필요하면 원본 SamsungOne 폰트를 서버에 올려 `font-family`를 교체하세요.

## 참고
- 문구 수정·가격 변경이 코드에서 바로 됩니다(이미지 다시 안 떠도 됨).
- 일부 브랜드 워터마크("AI DoorCam" 등)와 제품에 인쇄된 글자는 사진의 일부라 이미지에 남아 있습니다.
- 이미지에 글자를 그대로 둔 단순 분할 버전이 필요하면 별도 제공 가능합니다.
