[AI 도어캠 상세페이지 - 안정 버전 (권장)]

■ 방식
- 모든 마케팅/사진 구역 = 이미지(사진+글자 한 몸) → 절대 깨지지 않음
- FAQ / 제품 상세정보 표 / 하단 제품정보 = 진짜 HTML (자동 줄바꿈, 수정 쉬움)
- 모든 이미지에 alt 설명 텍스트 → SEO 반영

■ 왜 이 버전?
- 글자를 이미지 위에 얹는 '오버레이' 방식은 배경 플레이트가 손상되거나(사진 누락)
  폰트/폭 차이로 글자가 겹치는 문제가 있었음.
- 이 버전은 그런 위험이 없음.

■ 적용 (카페24)
1) images 폴더의 detail_01~30.jpg 를 서버에 업로드
2) index.html 의 src="images/..." 경로를 서버 URL로 일괄 변경
3) 상세 편집 HTML 모드에 붙여넣기
