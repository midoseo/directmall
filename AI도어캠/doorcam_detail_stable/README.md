# 에스원 AI 도어캠 상세페이지 — 퍼블리싱 파일 (카페24용)

## 구성
- `index.html` — 상세페이지 HTML (이미지 + 실제 텍스트 + 표)
- `images/` — 상세 이미지 30조각 (detail_01 ~ detail_30.jpg)

## 특징
- 긴 통이미지를 **30조각으로 분할**해 로딩이 빠르고 모바일에서 안정적입니다. (`loading="lazy"` 적용)
- **SEO 핵심 영역은 실제 HTML 텍스트**로 작성되어 검색엔진이 읽을 수 있습니다.
  - 자주 묻는 질문(FAQ)
  - 제품 상세정보 표
  - 제품/판매 정보(제품명·모델명·제조원 등)
- 모든 이미지에 **alt 설명 텍스트**가 들어가 있습니다.
- `<title>` / `<meta description>` 포함, 모바일 반응형.

## 에이전시 작업 안내 (이미지 경로 변경)
1. `images/` 폴더의 이미지 30개를 쇼핑몰 이미지 서버(FTP 또는 에디터)에 업로드합니다.
2. `index.html` 안의 `src="images/detail_XX.jpg"` 경로를 업로드된 실제 URL로 바꿉니다.
   - 예: `src="//myshop.cafe24.com/web/upload/detail/detail_01.jpg"`
   - 텍스트 에디터의 찾기·바꾸기로 `images/` → 실제 경로 접두어로 일괄 변경하면 편합니다.
3. 카페24 상품 상세 편집 > HTML 모드에서 `<div class="s1dc"> ... </div>` 와 상단 `<style>` 블록을 붙여넣습니다.
   (전체 `index.html`을 그대로 써도 되고, 스킨에 맞춰 body 안쪽만 이식해도 됩니다.)

## 상세영역 폭 조정
기본 폭은 860px입니다. 스킨의 상세영역이 더 넓으면 `<style>` 안의
`.s1dc{ max-width:860px; }` 값을 1000~1200px로 바꾸세요.

## 참고
- 이미지 텍스트와 화면 문구가 실제와 다를 수 있는 부분(마스킹·알림 화면 등)은 원본 표기를 유지했습니다.
- 원본 전체 이미지가 필요하면 `full.png`(1440×62802) 재추출본을 별도 요청하세요.
