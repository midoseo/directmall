# AED10021 상세페이지 — 카페24 업로드 가이드

## 파일 구성

| 파일 | 용도 |
|---|---|
| `aed10021_standalone.html` | **카페24에 올릴 최종 파일.** 이미지가 모두 base64로 파일 안에 포함되어 있어, 이 파일 하나만 있으면 어디서든 그대로 보입니다. |
| `aed10021.html` | 편집용 원본. 이미지가 `images/` 폴더의 파일을 상대경로로 불러오는 방식이라 로컬에서 수정하고 미리보기 하기 편합니다. **문구·디자인을 다시 수정할 때는 이 파일을 고치세요.** |
| `images/*.jpg`, `images/*.png` | 상세페이지에 쓰인 이미지 원본 6장 (제품 사진, 구성품 3종, 거치대 스탠드형/벽부형). |

> `aed10021_standalone.html`은 `aed10021.html`을 수정한 뒤 이미지를 base64로 다시 구워서 만든 결과물입니다. **`aed10021.html`을 고치면 `aed10021_standalone.html`도 같은 내용으로 다시 만들어야** 두 파일이 어긋나지 않습니다. (재생성이 필요하면 언제든 요청하세요.)

## 카페24 업로드 방법

1. 카페24 관리자 페이지 → **상품관리 > 상품등록/수정** → 해당 상품의 **상세설명** 편집 영역으로 이동
2. 에디터 툴바에서 **HTML 소스 편집** 버튼(흔히 `<>` 아이콘, "HTML" 또는 "소스" 라고 표시됨) 클릭
3. `aed10021_standalone.html` 파일을 텍스트 에디터(메모장, VS Code 등)로 열어 **전체 내용을 복사**
4. 카페24 HTML 소스 입력창에 **붙여넣기** 후 저장/적용
5. 미리보기로 이미지·레이아웃이 정상적으로 보이는지 확인

이미지가 파일 안에 이미 포함되어 있으므로, 별도로 이미지를 카페24 이미지 서버에 업로드하거나 외부 URL을 연결할 필요가 없습니다.

## 주의사항

- **파일 용량:** `aed10021_standalone.html`은 약 **320KB**입니다. 제품·구성품 원본 사진(PNG, 합계 약 940KB)을 JPEG로 재인코딩·리사이즈해서 용량을 크게 줄인 뒤 임베드했습니다 (화질 저하는 미미합니다). 카페24 HTML 편집창에 붙여넣기가 안 되거나 저장 시 잘리는 문제가 있다면, 에디터 자체의 글자수/용량 제한일 수 있으니 카페24 고객센터에 상세설명 HTML 용량 제한을 확인해보세요.
- **거치대 이미지:** 스탠드형·벽부형 거치대 사진은 AED10002 상세페이지 작업 때 만든, 흰 배경을 투명 처리한 실사 이미지(`img_holder_stand.png`, `img_holder_wall.png`)를 그대로 재사용했습니다. 다른 이미지로 교체하고 싶다면 `aed10021.html`의 해당 `<img>` 경로를 원하는 파일로 바꾼 뒤 standalone 파일을 다시 생성하면 됩니다.
- **공통 문구:** 히어로 카피, "주요 서비스 및 특장점", 거치대, 자주 묻는 질문 섹션은 AED10002 상세페이지와 문구·레이아웃을 통일했습니다. 단, FAQ의 A/S 전화번호(070-7092-9973)와 사용온도(-20℃~+43℃)는 AED10021 고유 스펙 그대로 유지했습니다 — AED10002 것을 그대로 옮기면 잘못된 정보가 되기 때문입니다. 향후 두 페이지 중 하나만 문구를 바꾸면 서로 어긋날 수 있으니, 공통 섹션을 고칠 땐 두 상품 페이지를 함께 확인해주세요.
- **폰트:** 본문에 Pretendard 웹폰트(CDN)를 사용합니다. 카페24 상세설명 영역은 보통 외부 리소스 로딩을 막지 않지만, 만약 폰트가 깨져 보이면 카페24 기본 폰트로 자동 대체되니 레이아웃 자체는 깨지지 않습니다.
- **반응형:** 모바일 화면(560px 이하)에 맞춘 반응형 스타일이 포함되어 있어 PC/모바일 카페24 페이지 모두에서 자연스럽게 보입니다.

## 다시 수정하고 싶을 때

1. `aed10021.html`을 열어 원하는 문구/스타일을 수정
2. 브라우저로 `aed10021.html`을 직접 열어 미리보기 확인 (`images/` 폴더 이미지들을 그대로 불러옵니다)
3. 수정이 끝나면 이미지 임베딩 작업을 다시 진행해 `aed10021_standalone.html`을 갱신 (필요하면 언제든 요청 주세요)
4. 갱신된 `aed10021_standalone.html`을 카페24에 다시 붙여넣기
