# AED10002 상세페이지 — 카페24 업로드 가이드

## 파일 구성

| 파일 | 용도 |
|---|---|
| `aed10002_standalone.html` | **카페24에 올릴 최종 파일.** 이미지가 모두 base64로 파일 안에 포함되어 있어, 이 파일 하나만 있으면 어디서든 그대로 보입니다. |
| `aed10002.html` | 편집용 원본. 이미지가 같은 폴더의 파일(`img_...png/jpg`)을 상대경로로 불러오는 방식이라 로컬에서 수정하고 미리보기 하기 편합니다. **문구·디자인을 다시 수정할 때는 이 파일을 고치세요.** |
| `img_*.png`, `img_*.jpg` | 상세페이지에 쓰인 이미지 원본 7장 (제품 사진, 구성품 4종, 거치대 스탠드형/벽부형). |

> `aed10002_standalone.html`은 `aed10002.html`을 수정한 뒤 이미지를 base64로 다시 구워서 만든 결과물입니다. **`aed10002.html`을 고치면 `aed10002_standalone.html`도 같은 내용으로 다시 만들어야** 두 파일이 어긋나지 않습니다. (재생성이 필요하면 언제든 요청하세요.)

## 카페24 업로드 방법

1. 카페24 관리자 페이지 → **상품관리 > 상품등록/수정** → 해당 상품의 **상세설명** 편집 영역으로 이동
2. 에디터 툴바에서 **HTML 소스 편집** 버튼(흔히 `<>` 아이콘, "HTML" 또는 "소스" 라고 표시됨) 클릭
3. `aed10002_standalone.html` 파일을 텍스트 에디터(메모장, VS Code 등)로 열어 **전체 내용을 복사**
4. 카페24 HTML 소스 입력창에 **붙여넣기** 후 저장/적용
5. 미리보기로 이미지·레이아웃이 정상적으로 보이는지 확인

이미지가 파일 안에 이미 포함되어 있으므로, 별도로 이미지를 카페24 이미지 서버에 업로드하거나 외부 URL을 연결할 필요가 없습니다.

## 주의사항

- **파일 용량:** `aed10002_standalone.html`은 약 **400KB**입니다 (이미지 7장을 base64로 인코딩해서 포함하고 있어 원본 이미지 용량 합계보다 33% 정도 더 큽니다). 카페24 HTML 편집창에 붙여넣기가 안 되거나 저장 시 잘리는 문제가 있다면, 에디터 자체의 글자수/용량 제한일 수 있으니 카페24 고객센터에 상세설명 HTML 용량 제한을 확인해보세요.
- **거치대 이미지:** 스탠드형·벽부형 거치대 사진은 상위 `AED` 폴더에 있던 실제 제품 실사 이미지(`AED2160E_거치대스탠드형_정면.jpg`, `AED2150W_거치대벽부형_좌측.jpg`)를 리사이즈해서 사용했습니다. 다른 각도·이미지로 교체하고 싶다면 `aed10002.html`의 `img_holder_stand.jpg` / `img_holder_wall.jpg` 부분을 원하는 파일로 바꾼 뒤 standalone 파일을 다시 생성하면 됩니다.
- **폰트:** 본문에 Pretendard 웹폰트(CDN)를 사용합니다. 카페24 상세설명 영역은 보통 외부 리소스 로딩을 막지 않지만, 만약 폰트가 깨져 보이면 카페24 기본 폰트로 자동 대체되니 레이아웃 자체는 깨지지 않습니다.
- **반응형:** 모바일 화면(560px 이하)에 맞춘 반응형 스타일이 포함되어 있어 PC/모바일 카페24 페이지 모두에서 자연스럽게 보입니다.

## 다시 수정하고 싶을 때

1. `aed10002.html`을 열어 원하는 문구/스타일을 수정
2. 브라우저로 `aed10002.html`을 직접 열어 미리보기 확인 (같은 폴더 이미지들을 그대로 불러옵니다)
3. 수정이 끝나면 이미지 임베딩 작업을 다시 진행해 `aed10002_standalone.html`을 갱신 (필요하면 언제든 요청 주세요)
4. 갱신된 `aed10002_standalone.html`을 카페24에 다시 붙여넣기
